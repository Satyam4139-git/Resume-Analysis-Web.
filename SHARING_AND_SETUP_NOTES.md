# Project update notes

## UI changes
- Refreshed the existing visual system for a cleaner, more modern career dashboard.
- Improved responsive layouts for smaller screens.
- Added drag-and-drop support for PDF and DOCX resume selection.
- Existing HTML element IDs, API calls, and backend integrations were preserved.

## Setup
1. Create and activate a Python virtual environment.
2. Install dependencies with `pip install -r requirements.txt`.
3. Copy `.env.example` to `.env` and fill in your own credentials.
4. Start the backend using the project's existing run instructions.

## Privacy and security
- The real `.env` file was intentionally excluded from this ZIP.
- Uploaded resume PDFs and generated Python caches/virtual environments were excluded.
- Do not commit API keys, OAuth secrets, session secrets, or personal resumes to a public repository.
